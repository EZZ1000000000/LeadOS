platform: DIRECTORY

## بتجيب إيه
- بيزنسات مسجلة في أدلة الأعمال — اسم + تصنيف + أحيانًا تليفون وموقع.
- أفضل مصدر لقوائم الاتصال الصافية (بيزنس مؤهل زي الخرايط بالظبط).

## لغتها
- `<الموضوع> دليل شركات` — وبذور: «شركات برمجة القاهرة»، «شركات تسويق الكتروني مصر»، «مصانع أغذية مصر»، «شركات اعلانات مصر».

## قواعد الجودة
- الدليل = قائمة بيزنس حقيقية — بيتقبل تلقائيًا كـ MARKET_LIST مع score≥45.
- ممنوع صفحات «أفضل 302 دكتور» (قوائم category مش بيزنس) — ريجكس جاهز.

## فخاخ
- الأدلة القديمة ممكن يكون فيها أرقام ميتة — وثّق التليفون زي ما هو.
